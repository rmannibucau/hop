= Kubernetes Watch

== Description

The *Kubernetes Watch* transform opens a watch on a resource list and writes one output row per watch event,
using a xref:metadata-types/kubernetes/kubernetes-connection.adoc[Kubernetes Connection]. Watch events carry a
type (`ADDED`, `MODIFIED`, `DELETED`, `ERROR`) and the resource object.

NOTE: The current implementation performs a one-shot watch request and processes the returned events rather
than keeping an interactive streaming channel open indefinitely.

== Options

[options="header", width="90%", cols="1,3"]
|===
|Option|Description
|Kubernetes connection|Name of the Kubernetes connection metadata to use.
|Kind|The resource kind to watch (for example `Pod`, `Service`).
|Namespace|The namespace to watch. Defaults to the connection namespace.
|Label selector|An optional label selector to narrow the watched resources.
|Output field name|Name of the output field that receives the event type. Default `watch_event`.
|Include body|When enabled, the full resource object JSON is added to the output row.
|===
