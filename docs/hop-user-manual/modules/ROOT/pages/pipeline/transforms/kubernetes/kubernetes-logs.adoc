= Kubernetes Logs

== Description

The *Kubernetes Logs* transform fetches the logs of a pod container and writes one output row per log line,
using a xref:metadata-types/kubernetes/kubernetes-connection.adoc[Kubernetes Connection]. The pod name can be
read from an input field or configured directly.

== Options

[options="header", width="90%", cols="1,3"]
|===
|Option|Description
|Kubernetes connection|Name of the Kubernetes connection metadata to use.
|Pod|A fixed pod name, used when no pod name field is configured.
|Pod name field|The input field that provides the pod name.
|Namespace|The namespace of the pod. Defaults to the connection namespace.
|Container|The container whose logs are fetched. Empty = the pod's single (or default) container.
|Tail lines|Only return the last N log lines (`0` = all lines).
|Output field name|Name of the output field that receives each log line. Default `log_line`.
|===
