= Kubernetes Delete

== Description

The *Kubernetes Delete* transform deletes a Kubernetes resource for each incoming row, using a
xref:metadata-types/kubernetes/kubernetes-connection.adoc[Kubernetes Connection]. The resource name is taken
from a configured field or from a fixed name, and it can also be narrowed with a label selector.

== Options

[options="header", width="90%", cols="1,3"]
|===
|Option|Description
|Kubernetes connection|Name of the Kubernetes connection metadata to use.
|Kind|The resource kind to delete (for example `Pod`, `Service`).
|Name|A fixed resource name, used when no name field is configured.
|Name field name|The input field that provides the resource name per row.
|Namespace|The namespace of the resource. Defaults to the connection namespace.
|Label selector|An optional label selector; when set, matching resources are listed and deleted.
|Ignore not found|When enabled, deleting a missing resource is not an error.
|Output field name|Name of the output field that receives `true`/`false` for deletion success. Default `deleted`.
|===
