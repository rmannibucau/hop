= Kubernetes Exec

== Description

The *Kubernetes Exec* action verifies that the referenced pod is reachable, resolves the target container and
streams the container logs to the workflow log, using a
xref:metadata-types/kubernetes/kubernetes-connection.adoc[Kubernetes Connection].

NOTE: The fused Kubernetes client used by Hop does not expose an interactive exec channel. When a `command` is
configured, the action records that limitation in the log and fails the workflow rather than silently ignoring
the request. Without a command, the pod logs are written to the workflow log and the action succeeds if the pod
was found.

== Options

[options="header", width="90%", cols="1,3"]
|===
|Option|Description
|Kubernetes connection|Name of the Kubernetes connection metadata to use.
|Pod|The name of the pod to target.
|Container|The container within the pod. Empty = the first container of the pod.
|Namespace|The namespace of the pod.
|Command|An optional command to run. Interactive exec is not currently supported by the underlying client.
|Wait timeout (seconds)|Maximum time to wait when probing the pod.
|===
